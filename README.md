# Smart Oil Palm Price Calendar

เว็บปฏิทินพยากรณ์ราคาปาล์มน้ำมันประเทศไทย แสดงราคาคาดการณ์รายวันในรูปแบบปฏิทินรายเดือน คล้ายเว็บดูราคาตั๋วเครื่องบิน

## เปิดใช้งานเว็บ

- เว็บหลัก: [https://ttumtr.github.io/smart-oil-palm-price-calendar/](https://ttumtr.github.io/smart-oil-palm-price-calendar/)

## ช่วงข้อมูลพยากรณ์

- เว็บหลัก: 1 มิถุนายน 2569 ถึง 31 พฤษภาคม 2570

## โมเดลที่ใช้

ระบบใช้โมเดล `Adaptive seasonal ridge regression` โดยเรียนรู้จากข้อมูลราคาปาล์มน้ำมันย้อนหลังของประเทศไทย แล้วปรับระดับราคาตามข้อมูลล่าสุดเพื่อลดความคลาดเคลื่อน

ผลการทดสอบล่าสุด:

- Backtest MAPE: 9.46%
- RMSE: 0.812

## ไฟล์สำคัญ

- `index.html` หน้าเว็บหลัก
- `styles.css` หรือ `assets/styles.css` ไฟล์ตกแต่งหน้าเว็บ
- `app.js` หรือ `assets/app.js` ไฟล์ควบคุมการแสดงผลปฏิทิน
- `predictions_2569_2570.js` ข้อมูลพยากรณ์สำหรับเว็บหลัก
- `predictions_personal_2569_2570.js` ข้อมูลพยากรณ์สำหรับเว็บส่วนตัว
- `scripts/build_predictions.js` สคริปต์สร้างข้อมูลพยากรณ์

## แหล่งข้อมูล

ใช้ข้อมูลราคาผลปาล์มและน้ำมันปาล์มรายวันจากกรมการค้าภายใน กระทรวงพาณิชย์ และนำมาจัดรูปแบบเป็นข้อมูลอนุกรมเวลาสำหรับการพยากรณ์

## หมายเหตุ

ราคาที่แสดงเป็นแนวโน้มเชิงสถิติ ไม่ใช่ราคาซื้อขายยืนยันจากลานเทหรือโรงงาน ผู้ใช้ควรตรวจสอบราคาจริงในพื้นที่ประกอบก่อนตัดสินใจ
