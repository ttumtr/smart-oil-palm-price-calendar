# Smart Oil Palm Price Calendar

เว็บปฏิทินพยากรณ์ราคาปาล์มน้ำมันประเทศไทย แสดงราคาคาดการณ์รายวันตั้งแต่ 1 มิถุนายน 2569 ถึง 31 พฤษภาคม 2570 ในรูปแบบคล้ายเว็บดูราคาตั๋วเครื่องบินรายเดือน

## วิธีรัน

```bash
node scripts/build_predictions.js
node scripts/serve.js
```

จากนั้นเปิด `http://localhost:4173`

## ข้อมูลและโมเดล

- แหล่งข้อมูลหลัก: กรมการค้าภายใน กระทรวงพาณิชย์ หน้าราคาผลปาล์มและน้ำมันปาล์มรายวัน
- ชุดข้อมูลที่สร้าง: `data/historical_oil_palm_prices.csv`
- ไฟล์พยากรณ์สำหรับหน้าเว็บ: `assets/data/predictions_2569_2570.json`
- โมเดล: adaptive seasonal ridge regression ที่เรียนรู้ trend, seasonality และปรับระดับราคาจากข้อมูลล่าสุดเพื่อลดความคลาดเคลื่อน

ราคาพยากรณ์เป็นแนวโน้มเชิงสถิติ ไม่ใช่ราคาซื้อขายยืนยันจากลานเทหรือโรงงาน
